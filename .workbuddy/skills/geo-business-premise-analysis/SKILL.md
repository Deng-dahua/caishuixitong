# 经营实质地理分析（点→面推理技能）

## 核心理念

不止于看一个数字，而是把业务放到现实地理空间里验证其合理性。从一个风险点（如加工费来源异常）推理出面的风险（全链条经营实质存疑）。

## 点→面推理框架

```
点（单点发现）
  ↓ 数据扩展
线（关联维度）— 供应商地址 / 客户地址 / 加工商地址 / 运输成本
  ↓ 交叉验证
面（综合结论）— 全链条货物流物证链是否完整
```

## 分析步骤

### Step 1: 定位企业地址
- 从公司工商登记地址提取城市（联网查询 + 发票购买方名称交叉确认）
- 确定所在地产业集群特征（中山=纺织集群、东莞=电子/模具集群等）
- 无论贸易型还是生产型，只要涉及实物商品，均需验证物流合理性

### Step 2: 单点发现——检测异常信号
- 逐张发票提取客户/供应商公司名称→提取城市前缀
- 统计本地 vs 外地供应商/客户/加工商数量
- 检测运输/物流/快递类费用是否为零
- 如发现外地加工费→标记为单点风险信号

### Step 3: 扩展推理（点→面）
将单点发现扩展到三维交叉：
- **维度A**: 进项供应商地址分布（原材料从哪里来）
- **维度B**: 销项客户地址分布（成品到哪里去）
- **维度C**: 加工费供应商地址分布（中间加工在哪里做）
- **维度D**: 运输成本存在性（货物流的物证链）

**判断逻辑**：
- 三个维度地址互不重叠 + 零运输成本 → 货物流物证链断裂 → 全链条经营实质存疑
- 加工费应发生在企业所在地（靠近产业集群是正常商业逻辑）
- 外地加工商 + 本地有同类加工资源 → 商业合理性存疑
- 重物（纺织/建材/机械/钢材/食品等）跨省运输必有运输费，无运输费 = 货物流无法验证

### Step 4: 交叉验证——确定风险等级
| 条件组合 | 结论 | 风险等级 |
|---------|------|---------|
| 外地供应商≥3 + 运输费=0 | 货物流存疑 | 高风险 |
| 加工商全在外地 + 本地有产业群 | 加工链条存疑 | 高风险 |
| 三组地址全不同 + 运输费=0 | 全链条断裂 | 高风险 |
| 仅外地供应商（有运输费） | 正常跨省采购 | 信息 |

## 重物行业判断标准

以下行业的原材料和成品均为重物，跨省运输必然产生可观的运输费用（通常占货值3%-8%）：

| 行业 | 重物特征 |
|------|---------|
| 纺织制造/印染/服装 | 棉纱、坯布、面料、服装均为重物 |
| 建材/建筑 | 钢筋、水泥、砂石、砖、瓷砖 |
| 机械制造/五金 | 钢材、铸件、设备 |
| 家具/木材 | 木材、板材、家具 |
| 食品加工 | 面粉、粮油、食品 |
| 化工/塑料 | 化工品、塑料原料 |
| 电子/电器 | 虽相对轻但批量运输仍有可观的物流成本 |

## 加工费地理合理性判断

| 场景 | 判断 |
|------|------|
| 加工商在企业所在地（同城） | 合理——产业集群效应 |
| 加工商在外地 + 当地有同类加工资源 | 存疑——为何舍近求远？ |
| 加工商在外地 + 当地无同类加工资源 | 可解释——当地无此加工能力 |
| 加工商城市 ≠ 供应商城市 ≠ 客户城市 | 高度存疑——三地分离 + 无运输费 = 全链条断裂 |

## 与系统集成

该技能已实现为 `_domain_business_premise_geo()` 函数，位于 `main.py`，自动接入一键分析链路。

调用参数：`_domain_business_premise_geo(bank_txs, invoices, docs)`

返回值：`findings` 列表，包含三项核心发现：
- `重物跨省经营缺运输成本` (高风险/score=8)
- `外地加工费存疑` (高风险/score=6-8)
- `全链条经营实质地理异常` (高风险/score=9，三地分离+零运输时触发)

㉖ 经营实质点面推理法——从地址→运输→加工费多点交叉，单点风险扩展为全链条经营实质判断。
