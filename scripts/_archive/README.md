归档 ≠ 删除：文件本体保留在磁盘，仅移出工作树、不进版本库，供追溯。

## 准入判定（必须同时成立）

1. **确认为历史产物**——该文件的产出链路已废弃（上游模块已重写/合并/删除）；
2. **全仓零引用**——`grep -rn <文件名或符号>` 在 `engine/ tests/ tools/ scripts/ *.py` 中除了本目录与记忆/日志之外无任何命中；
3. **不是唯一权威源**——所承载的知识已收敛到 `engine/` 内某个单一权威模块（否则删了会复发）。
