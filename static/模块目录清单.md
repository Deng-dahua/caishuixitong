## 二、稽查分析管道（Phase 1-4）
### （一）Phase 1 初查
1. 企业画像推断 — 行业/经营模式/规模
2. 财务快照 — 销项/进项/银行/工资汇总
3. 信号检测 — 购销倒挂/季度冲量/供应商集中度
4. 资料质量评估 — 数据完整性和可用性评分
5. 自适应权重调整 — 用户反馈→信号阈值动态修正
### （二）Phase 2 深挖
1. 信号→域映射表 — 29域按需激活
2. 18域分析引擎 — 资金追踪/发票审计/社保工资/进销存等
3. 主营业务成本识别 — 三层分类（日常报销/主营成本/重大费用）
4. 行业自适应闸门 — 服务行业自动跳过进销存分析
### （三）Phase 3 交叉验证
1. 信号叠加检测 — 多信号并发提级
2. 冲突消解 — 付款未匹配 vs 员工报销模式
3. 结论互证 — 单一数据源信号不报告
4. 因果网络分析 — 共现矩阵+因果边发现
### （四）Phase 4 综合定性
1. 风险评级 — 高/中/低三级评定
2. 优先级排序 — P0/P1/P2分级整改建议
3. Benford检验 — 数值分布自然性检测
4. 综合结论生成 — 叙事链+证据链闭环

## 三、AGI 核心能力
### （一）基础能力
1. 持续记忆 — 历史分析经验积累与检索
2. 自主决策 — 不确定性量化和自主调查
3. 一次学会 — 用户纠正一次即记住
4. 反事实推理 — "如果...会怎样"推演
### （二）高级推理
1. 因果发现 — 贝叶斯条件概率→自动注册推理规则
2. 创造性假设 — 类比推理+未知模式探索
3. 法律推理 — 三段论：法条大前提+事实小前提→结论
4. 语义理解 — 品名同义扩展/法条意图匹配
5. SCM因果推理 — do-calculus/反事实/因果方向判定
### （三）假设验证
1. 假设-验证引擎 — 信号检测→竞争假设→证据搜索→加权判决
2. 未知模式检测 — 系统认知边界探測→智能路由
### （四）自审与学习
1. 自审引擎 — 报告质量自审+规则自动调整
2. 知识管线 — 联通16+模块到AGI学习系统
3. 跨企业关联 — 共享供应商/客户/人员自动发现
4. 跨公司合成 — 多企业模式提炼通用规则
### （五）自主进化
1. 自主工具调用 — AGI自主选择分析工具
2. 无声学习 — 不被察觉的持续优化
3. 规则自动发现 — 模块效率分析/信号模式对比
4. 法规自更新 — 联网跟踪税法变动
