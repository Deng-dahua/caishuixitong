# 财税风险防控系统 — 模块目录清单（2026-07-03 精简版）

## 一、智能大脑
### （一）管道调度
1. 调度中枢 — 数据画像→模块资格判定→依赖求解→按需调度
2. 成长曲线 — 渐进学习（模块信任度+调度策略优化）
3. 知识库 — 统一知识库引擎（政策/因果边/信号模式/语义字典）
4. 自动巡检 — 定期重分析已分析企业，检测学习效果
### （二）推理引擎（Phase 1-4）
1. Phase 1 初查 — 企业画像/财务快照/信号检测/资料质量/自适应权重
2. Phase 2 深挖 — 信号→域映射/18域按需激活/主营成本识别/行业闸门
3. Phase 3 交叉验证 — 信号叠加/冲突消解/结论互证/因果网络
4. Phase 4 综合定性 — 风险P0-P2评级/Benford检验/综合结论
### （三）AGI核心推理（一键分析时自动运行）
1. 处长级研判 — 不确定性量化+经济实质穿透+跨税种综合判断
2. 反事实推理 — "如果...会怎样"推演
3. 泛化学习 — 跨案例模式提炼
4. 因果网络 — 共现矩阵+因果边发现+SCM do-calculus
5. 知识图谱 — 实体-关系-属性图+多跳推理
6. 语义推理 — 品名同义扩展+法条意图匹配+行业术语归一化
7. 未知模式检测 — 系统认知边界探測+智能路由
8. 假设验证 — 竞争假设生成→证据搜索→加权判决
9. 跨企业关联 — 共享供应商/客户/人员自动发现
10. 跨域协商 — 消解层/降级层/协同层三层对话
11. 事件总线 — 模块间实时通信中枢
### （四）学习反馈（✏️驱动闭环）
1. 税务合规指令 — 1608条涉税风险税务合规指令
2. 线索链 — 437条跨域线索
3. 证据链 — 781条跨域证据
4. 分析链 — 48条跨域分析
5. 纠正规则库 — ✏️编辑/审核/追问/重置→record_correction→自动应用
6. 五链传播 — 纠正规则→总结提炼→更新指令/线索/证据/分析/方法论
7. 自愈引擎 — 错误检测→规则生成→auto_apply_fixes→inject_new_rule
8. 自适应权重 — audit_feedback→_adjust_signal_weights→Phase1信号修正
9. 税收优惠政策核实 — 应享尽享/错享纠正/临界达标
10. 规则发现 — 模块效率分析+纠正模式归纳+信号模式对比
### （五）质量保障
1. 全链路质量保障体系 — 质量保障与合规审计
2. 合规门禁 — 12项质量标准事前拦截（非阻塞+阻塞双模式）
3. 元认知自审 — meta_loop.run() 自动运行（已接入管道）
4. 运行仪表盘 — Phase 1-4 完整状态可视化+AGI合并大脑日志
5. 引擎能力维度 — 25维度能力矩阵展示

## 二、税务合规分析管道
### （一）文件解析
1. 格式支持 — Excel/PDF/Word/图片OCR
2. 类型识别（13类） — 银行流水/销进项发票/进项抵扣/工资/社保/公积金等
3. 智能识别 — 四步推理（文件名→列头→数据→公司匹配）+智能兜底+空行过滤
### （二）Phase 1 初查
1. 企业画像推断 — 行业/经营模式/规模
2. 财务快照 — 销项/进项/银行/工资汇总
3. 信号检测 — 购销倒挂/季度冲量/供应商集中度
4. 资料质量评估 — 数据完整性和可用性评分
5. 自适应权重调整 — 用户反馈→信号阈值动态修正
### （三）Phase 2 深挖
1. 信号→域映射 — 29域按需激活
2. 18域分析引擎 — 资金追踪/发票审计/社保工资/进销存等
3. 主营业务成本识别 — 三层分类（日常报销/主营成本/重大费用）
4. 行业自适应闸门 — 服务行业自动跳过进销存分析
### （四）Phase 3 交叉验证
1. 信号叠加检测 — 多信号并发提级
2. 冲突消解 — 矛盾信号自动消解
3. 结论互证 — 单一数据源不报告
### （五）Phase 4 综合定性
1. 风险评级 — 高/中/低三级
2. 分级建议 — P0立即处理/P1重点关注/P2持续关注
3. Benford检验 — 数值分布自然性检测
4. 综合结论 — 叙事链+证据链闭环
### （六）报告生成
1. 七章一附件 — 标准税务合规报告
2. 12项质量自检 — 硬指标自动核查
3. 全链路追溯 — 规则ID→线索链ID→证据链ID→原始数据
4. 20场景模板 — 不同发现类型的审核话术
5. 报告编辑反馈 — ✏️段落/章节/发现→弹窗→编辑/审核/追问/重置
6. 标题层级 — h2章→h3节→h4小节，DOM驱动✏️涵盖范围
