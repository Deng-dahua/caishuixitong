# 账号设置(手机号注册)与修改密码 + 登录后先进角色设置

- 日期:2026-10-15 凌晨
- 用户需求:①账号设置页:填手机号,**初始密码=手机号**,有修改密码页
  ②登录后先进「角色设置」页(系统角色权限集中于此),再进系统主页
- 提交:`账号角色流`(本文件为记录)

---

## 一、账号设置页 `/account-setup`(免登录,新页面)

- 表单:**手机号**(1 开头 11 位,必填)+ 姓名(选填);
- 提交 `POST /api/auth/register`(免登录白名单已登记):
  账号=手机号,**初始密码=手机号**,`must_change_password=true`,角色=user;
- 手机号重复 ⇒ 400「该手机号已注册」;
- 成功页展示"账号=手机号 / 初始密码=手机号 / 首次登录后请立即修改密码"。
- 入口:登录页底部「没有账号?去账号设置 →」。

**密码策略的关键处理**:`hash_password` 内置 `validate_password`(≥12 位+三类),
手机号 11 位天然过不了 ⇒ `hash_password`/`create_user` 追加**可选**
`skip_policy_check`(默认 False,既有调用零影响),**仅注册初始密码使用**;
弱初始密由 `must_change_password` 强制改密兜底。

## 二、修改密码页 `/change-password`(需登录,新页面)

- 表单:原密码 / 新密码 / 确认;`POST /api/auth/change-password`(双前缀同时注册);
- 后端新函数 `security.change_password_with_old`:**验证旧密码** ⇒ 写新密码 ⇒
  **清 must_change_password** ⇒ 撤销全部会话(需重新登录);
- **新密码走系统全策略**(≥12 位 + 三类,与全局一致;弱密 400 + 中文提示);
- 原密码错误 ⇒ 400,审计留痕;
- 入口:侧边栏「三、系统」新增「🔑 修改密码」(所有登录用户,18→19 项);
- 未登录访问 ⇒ 302 去登录;**首次登录(初始密码=手机号)会被强制跳到本页**。

## 三、登录流(三分支)

`login` 成功后按登录响应分发:

| 条件 | 去向 |
|---|---|
| `must_change_password=true`(手机号初始密首登) | `/change-password`(强制改密) |
| `role=admin` | **`/roles`(角色设置页)** —— 系统角色权限集中于此 |
| 其他(普通用户) | `/`(系统主页) |

「角色管理」页 toolbar 新增绿色「**进入系统主页 →**」按钮。

## 四、其他改动
