## 2 税率测算表（唯一权威 `engine/tax_impact.py::_RATES`）

| 税种/项目 | 税率 | 口径说明 |
|---|---|---|
| 增值税 | 0.13 | 未取得销项税额明细，按 13% 法定上限口径测算；实际以票面适用税率（13%/9%/6%/3%）复核 |
| 企业所得税 | 0.25 | 按 25% 法定税率测算；小型微利企业另有优惠，实际以汇算清缴为准 |
| 个人所得税 | 0.03 | 按工资薪金/劳务报酬 3% 起点档测算；实际按超额累进税率计算 |
| 印花税 | 0.0003 | 按购销合同 0.03% 测算；实际按对应税目税率核对 |
| 城市维护建设税 | 0.07 | 按市区 7% 测算；县城/建制镇 5%、其他地区 1%，以企业实际所在地为准（《中华人民共和国城市维护建设税暂行条例》第二条） |
| 教育费附加 | 0.03 | 按增值税额的 3% 测算（《征收教育费附加暂行规定》第三条） |
| 地方教育附加 | 0.02 | 按增值税额的 2% 测算（《地方教育附加征收使用管理办法》第三条） |
| 城建税及教育费附加 | 0.12 | 按增值税额的 12%（城建税 7%＋教育费附加 3%＋地方教育附加 2%）合并测算；本项发现已单独列示「城市维护建设税」时不再重复加计 |
| 土地增值税 | 未量化 | 四级超率累进税率（30%~60%），须按增值额与扣除项目分项计算；本轮未取得分项目数据 ⇒ 未量化 |
| 房产税 | 未量化 | 从价计征 1.2%（原值减除 10%~30%）或从租计征 12%（另有个人住房优惠），适用口径取决于计税方式 ⇒ 未量化 |
| 城镇土地使用税 | 未量化 | 定额税率（按大/中/小城市与土地等级每平方米年税额），须先定税额标准 ⇒ 未量化 |
| 车船税 | 未量化 | 按车船种类、机驶吨位定额征收（年基准税额），须先定税目税额 ⇒ 未量化 |
| 契税 | 未量化 | 3%~5% 幅度税率（各地在幅度内确定），须按成交与当地规定核定 ⇒ 未量化 |
| 消费税 | 未量化 | 按应税消费品税目税率（如高档化妆品 15%、成品油等）分别计征 ⇒ 未量化 |
| 耕地占用税 | 未量化 | 定额税率（按地区人均耕地与税额幅度）⇒ 未量化 |
| 资源税 | 未量化 | 从价或从量，按税目幅度税率 ⇒ 未量化 |
| 环境保护税 | 未量化 | 按污染当量数 × 适用税额（大气/水按当量、固废与噪声按量）⇒ 未量化 |
| 车辆购置税 | 未量化 | 按应税车辆售价（不含税）10% 计征 ⇒ 未量化 |
| 烟叶税 | 未量化 | 按收购金额 20% 计征 ⇒ 未量化 |
| 船舶吨税 | 未量化 | 按净吨位定额（吨税税目表）⇒ 未量化 |
| 关税 | 未量化 | 按税则号列适用税率（最惠国/协定/特惠），须以报关口径核定 ⇒ 未量化 |
| 文化事业建设费 | 0.03 | 按广告业销售额（不含税）3% 计征（《财政部 税务总局关于文化事业建设费有关政策的通知》） |

（共 22 项；权威侧另有 `engine/tax_rates.py::CANON_RATES` 用于含税/不含税换算）

## 3 税种覆盖现状 vs 指令要求

| 税种 | 指令要求 | 现覆盖 | 缺口 |
|---|---|---|---|
| 增值税 | 风险指标/构成要件/证据要求/法规/计算规则 | 有（RL-VAT-*、进项差异、红冲等） | 税种包未成独立数据表 |
| 企业所得税 | 同上 | 有（扣除限额、贡献率、成本列支等） | 同上 |
| 个人所得税 | 同上 | 有（工资/社保/股权转让） | 同上 |
| 印花税 | 同上 | 有（RL-SPT-*） | 同上 |
| 城建税/教育费附加/地方教育附加 | 同上 | 部分（附加税费计税依据不匹配） | 税种包未成独立数据表 |
| 文化事业建设费 | 同上 | 有（RL-SPT-017） | 同上 |
| 社会保险费 | 同上 | 有（RL-PAY-001、payroll_rules.py） | 同上 |
| 房产税 / 土地增值税 | 同上 | **弱** | **缺** |

## 4 结论：税种包成熟度约 2~3 成

现状：税率/纳税调整逻辑散在 `verified_rule_engine.py` / `pipeline.py` / `tax_impact.py` 代码中，
**无独立税种包数据表**。P1 建议：按 `config/industry_params.json` 的成熟范式，新建
`config/tax_packs.json`（键=税种代码，值含 indicators/constituents/evidence/law/compute），
并配 `engine/tax_pack.py::validate()`，与 `industry_params` 同一套写法。
