## 二、★ 扫描域（`scan_domain`）—— 本批最重要的设计决定

### 2.1 反面教材（必须记住）

首版实现直接对**整个 `report_data`** 递归取字符串，结果：

| 假红 | 数量 | 真实来源 |
|---|---|---|
| 「未替换变量」 | **7314** | 一份**上传的 HTML 文件**（`{"p":"link"}` ×1680、`<script>` ×440、`<em>` ×421 …） |
| 「Markdown 残留 `__`」 | **3226** | JS 变量名 / Dunder 名（`__performancetime__`、`search-ai__tooltip`） |
| 「UI 残留 复制」 | 764 | 内部质量自检告警文案（「标准10_**防复制**」「疑似**复制粘贴**」） |
| 「重复段落」 | 1331 种 | `all_findings` / `domain_summary` 的字段级原始素材（不是报告正文） |

并且 `iter_texts` 还在 200000 块处**静默截断** —— 判据以为扫完了，其实没有。

### 2.2 正确做法：白名单 + 排除模式 + 上限留痕

```json
"scan_domain": {
  "mode": "allowlist",
  "include_top_keys": ["enterprise_readable_report", "summary_text", "overall_level",
                       "scope", "limitations", "conclusion_policy", "release_boundary", "stats"],
  "exclude_top_keys": ["file_results", "read_failures", "quality_report", "_one_click_pipeline",
                       "all_findings", "domain_summary", "scenario_execution", "comprehensive", "…"],
  "exclude_string_patterns": ["^https?://", "^\\s*<[a-zA-Z/!]", "^\\s*[.#@][a-zA-Z_-]+\\s*\\{",
                              "^\\s*(function|var|let|const|window\\.|document\\.)", "^\\{[\\s\\S]*\\}$"],
  "max_chars": 3000000,
  "truncation_policy": "REPORT_TRUNCATION_AS_ERROR"
}
```

- **用白名单**（不是黑名单）：新增键不会被自动纳入扫描，必须先登记。
- `iter_texts` 超限时**追加 `<<TRUNCATED…>>` 标记**（`truncation_policy` 要求升 ERROR）。
- 实现：`engine/quality_gates.report_surface(report_data)`。

## 三、UI 残留词表：只收"整词短语"

**教训**：单字词会命中正当业务表述。

| 错误词表 | 实测假红 |
|---|---|
| `导出` | 「社保经办机构**导出**明细」「开户行**导出**」（正当业务表述） |
| `复制` | 「疑似**复制**粘贴」「防**复制**」（内部自检告警） |
| `展开` | `**展开**</span>`（上传 HTML 里的 DOM） |

**正确词表**（`_UI_RESIDUE`）：
`下载 CSV` / `下载CSV` / `下载 csv` / `点击展开` / `展开全部` / `收起` / `复制链接` /
`导出：` / `导出:` / `导出CSV` / `导出 PDF` / `导出PDF` / `127.0.0.1` / `localhost:` /
`http://127.` / `点击查看` / `查看更多`

## 四、Markdown 残留词表

`**` / `##` / `|---` / `- [ ]` / ` ``` `
**不含 `__`**（会误伤 JS/CSS 变量名与 Dunder 名）。

## 五、未替换变量：形态过滤

正则：`(?<![{\w])\{[^{}\n]{1,24}\}(?![}\w])` 或 `\{\{[^{}\n]{1,40}\}\}` 或 `<[A-Za-z_\u4e00-\u9fa5]{2,20}>`

**形态过滤**（否则会把代码/样式当变量）：
- 内容长度 > 24 ⇒ 跳过
- 内容含 `; : { } ( ) [ ] = / \` ⇒ 跳过
- 内容为纯数字/符号 ⇒ 跳过

## 六、重复段落：渲染物按行拆段

**教训**：把整篇导出物当作**一个**字符串 ⇒ 段落计数恒为 1 ⇒ D5 永不触发。
渲染物必须**按换行拆段**（`render_text.split("\n")`），数据层字符串本身即段落。

阈值：同一 >25 字段落出现 **> 2 次** ⇒ ERROR。

**基准样本实测（真阳性抽样）**：

| 次数 | 段落 |
|---|---|
| 169 | 编制该期间差异调节表，逐笔说明差异原因（含税口径/跨期/未同步/漏记），必要时补充申报或更正账务。 |
| 92 | 未命中任何权威层（行业核心投入/通用成本/需上下文/通用费用）＋业态「服务型」无存货可比照 |
| 83 | 所需资料不齐时，该红线既不能认定、也不能排除，属检查受限。 |
| 32 | 该证据补齐后，若显示相关业务真实、口径一致 ⇒ 本项不成立（可自证清白）。 |
| 28 | 补齐上述资料后重新执行一键分析，由系统复查本事项是否已消除。 |
| 26 | 本项已查明的风险；未认定到构成要件（认定范围见本项说明） |

## 七、术语表：复用既有权威，不自造

| 用途 | 权威 |
|---|---|
| 模糊/不确定措辞 | `engine/report_wording.FORBIDDEN_VAGUE_TERMS` |
| 内部术语 → 业务语言 | `engine/text_guardrails._DIRECT_REPLACEMENTS`（约 120 组） |
| 通俗化词表 | `engine/plain_language.TERM_MAP` |
| 结论词 | `engine/argumentation._VERDICT_*`（映射在 `config/conclusion_grades.json`） |
| 等级词 | `engine/risk_levels.LEGAL_LEVELS` |

**现状缺口**：术语散在 `plain_language` / `report_wording` / `text_guardrails` **三处**
（`report_wording.py` 自述"两张词表各写一套"曾致漏判）。P1 建议合并为 `config/terms.json` 单一权威。

**实测**：D7 在基准样本报 736 处禁用模糊措辞（WARN）。
