## 2. 覆盖状态说明（本批新增第四态 `placeholder`）

V1.2 有 **90 条（占 40%）** 规则写作：

```
xxx and tax_treatment_abnormal      ← 「税务处理异常」无客观判据
xxx_abnormal = true                 ← 「异常」未定义
indicators > threshold              ← 「指标」未定义
```

这类规则**无法计算**。按项目铁律（**不得为凑数写永不触发的检测器 = 假闭环**），单列为 `placeholder`，
处理方式 `specify_first`（先由业务/税务专家把判据写成「可算字段 + 阈值」，再按 VR 落地）。

典型：
- **金融组 20 条中 13 条**为 placeholder（私募/公募/信托/REITs/PPP/EPC/BOT/ABS/保理/售后回租…）
- **行业组 10 条**为 placeholder（教育/医疗/养老/托育/体育/旅游/住宿/餐饮/娱乐/跨境电商）
- **ADM 组 12 条**为 placeholder（注册地址/发票领用/税控设备/申报篡改/延期缴税/总分机构/税收洼地/财政返还…）

**建议**：把「税务处理异常」类转为**人工复核底稿条目**（与既有 WS-01~04 人工兜底工作底稿同构），而不是检测器。
