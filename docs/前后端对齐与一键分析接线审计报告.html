七、与当前待办的关系（第一章为什么"前端没变化"）

  • 前端只渲染 oc.paragraphs，前端无需改；
  • 因此要重构第一章，唯一正确改造点是生成侧 engine/overall_conclusion.py :: build_overall_conclusion 的 paragraphs 组装；
  • 上一轮改的 engine/report_pipeline.py :: _render_text_from_report_data 只影响 output/editions/*.md 落盘，前端完全不读 —— 用户观察正确。
