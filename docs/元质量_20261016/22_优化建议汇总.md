## 四、准入结论（本轮做哪些、不做哪些）

**本轮（阶段 4~14）的定位是「评估」，不是「实施」** —— 依据指令 17：不修改现有规则、不擅自优化、只记录问题。因此：

| 归属 | 条数 | 说明 |
|---|---|---|
| **下一轮（立即）** | 2 | |
| **下一轮（优先）** | 8 | |
| 下一轮 | 13 | |
| 下一轮（评估后） | 9 | |
| 登记备用 | 11 | |

**如果只做 5 件事，应该是这 5 件**（按「投入小 × 救命」排序）：

| 序 | 编号 | 理由 |
|---|---|---|
| 1 | **S-10** 备份 | 没有备份 = 数据只有一份。演练证明 0.04 秒就能做一份快照，成本几乎为零，这是**唯一一条「不做就可能全丢」**的 |
| 2 | **PF-01** 法规库检索 | 用户每次打开法规库等 4~7 秒，且这是高频页；改法明确（装饰移到切片后 + 缓存），风险低 |
| 3 | **DOC-01 + CI-01** 端口与版本号 | 一个数字、一个 tag，解决「照文档装不上」与「说不清版本」 |
| 4 | **D-03** 服务自动重启 | 本轮多次「8001 未监听」，用户直接不可用；注册服务或加看护脚本即可 |
| 5 | **E-01** 知情同意 | 唯一一条「不做就构成合规瑕疵」的（个人信息保护法告知义务） |

> 其余 30 余条**不是不重要**，而是「不做也能用」；按优先级分批推进即可，不必一次做完。
