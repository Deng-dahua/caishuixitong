## 三、可验证的具体缺陷（不是“感觉不够”）

## 五、判定口径

| 判定 | 含义 |
|---|---|
| 完整 | 有独立、可执行、与实现一致的文档 |
| 部分可用 | 有文档但可达性受限（如被鉴权拦住） |
| 部分完整 | 有内容但散落多处、无统一基线 |
| 不完整 | 有零散提及，但**照它做不成事** |
| 缺失 | 按标题与内容双重检索均无 |

> ⚠ 本阶段的判定**不按文件名**，而是「**照它能不能做成事**」。例如「部署」二字在 23 篇文档里出现，但都不是可执行手册 —— 那不算有部署文档。
