# 用户手册

> 面向**使用系统的人**（企业财务、税务师、复核专家、管理员）。
> 一句话流程：**建账套 → 传资料 → 解析 → 分析 → 复核风险 → 出报告**。
> 系统只做"把材料里的疑点按规则摆出来 + 给法条依据"，**最终判断与责任仍在人**。

---

## 0. 先搞清楚三件事

1. **首页总览**（登录后默认落在「🏠 首页总览」）给四块数：待处理风险 / 超期未处置 /
   本项目资料 / 上次分析。数字都标了口径，鼠标悬停可看说明。
2. **侧栏**是唯一导航。看不到某些菜单 = 你的角色没有那个权限（不是系统坏了）。
3. **「缺失」不等于「0」**：报告和列表里出现「—」表示取不到数据，不是金额为零。

---

## 1. 建账套（一次性）

侧栏「新建企业账套」→ 填企业名称、统一社会信用代码（18 位）、行业、地区 →
保存。信用代码**不允许重复**，重复会明确提示。

> 账套是数据边界：资料、项目、报告都挂在账套下，看不到别的账套是**正常隔离**。

## 2. 上传资料

「📁 资料管理」→ 拖拽或点击上传。支持 Excel/PDF/图片等。

- 上传后状态是 **待解析**；
- 列表可按类型/状态筛选，可批量选择后删除（删除进**回收站**，可恢复）；
- 同名文件重复上传会被识别（旧版进回收站）。

## 3. 解析

「🔍 资料解析」→ 选项目 → 「开始解析」。

- 解析结果分「表 / 字段 / 问题」三个页签；
- **「问题」页签必须看**：它列出读不出来的行/列及原因（例如缺表头、合并单元格），
  这是后面分析结果可信度的前提；
- 字段可人工校正后保存（校正会留痕）。

## 4. 分析

「📊 分析任务」→ 选项目 → 「开始稽查分析」→ 等进度到 100%。

- 分析是**异步任务**，可以离开页面，回来在列表里看进度；
- 每一步都有状态，失败会给出失败步骤与原因；
- 同一项目重复分析会生成**新作业**（不是覆盖），便于对比。

## 5. 复核风险（核心工作）

「⚠️ 风险复核」→ 选项目 → 列表按风险等级排序。

每条风险给三样东西：**是什么**（结论 + 依据）、**为什么**（命中的规则与金额口径）、
**怎么办**（法条依据 + 整改建议）。

可执行动作（受角色限制）：

| 动作 | 含义 | 说明 |
|---|---|---|
| 确认 | 认可该风险成立 | 之后不能再改判「误报」（可整改/排除/重开） |
| 整改 | 已补正 | 需填整改说明 |
| 排除 / 误报 | 认定为非风险 | 需填理由，留痕 |
| 仅批注 | 只加意见不改状态 | 复核专家常用 |
| 重开 | 回到待处理 | 用于重新判断，**会留痕** |

多选后可批量处置（有上限，避免误操作）。

## 6. 出报告

「📄 报告」→ 选项目 → 「生成报告」→ 选版本（内部底稿 / 对外版）。

- 报告里的每条结论都能回溯到规则与法条，页内可查；
- 报告模板可在「报告模板」页调整章节顺序与侧重（**不增删风险事项**）；
- 版本历史可对比，已生成的报告不会被覆盖。

## 8. 常见问题

**Q：菜单少了几个？**
A：角色权限不同。找管理员确认你的角色，或看「角色管理」里的权限点。

**Q：点按钮提示 403？**
A：前端隐藏只是体验，服务端才是真拦截。403 说明你的账号没有该权限点。

**Q：报告里出现「—」？**
A：数据取不到（缺失），**不是 0**。按页面提示补齐资料后重新分析。

**Q：删错了资料？**
A：删除进回收站（`data/trash/`），找管理员恢复。

**Q：系统会自己备份吗？**
A：会。每日自动备份（默认保留 14 份），管理员可在「💾 备份与恢复」页立即备份并校验。
**注意**：备份不含上传原件，原件请由 IT 单独做文件系统备份。

**Q：结论能直接当申报依据吗？**
A：不能。系统给的是**线索与依据**，须由税务师/财务复核后使用；系统内所有结论均标注
"不构成税务鉴证意见"。
