### 2.1 D0（数据表健康闸门）——**为什么必须有它**

**实测事故（本批收口时真实发生）**：`config/doc_consistency.json` 被写入一处**半角引号** ⇒ JSON 非法
⇒ 核心 `_load()` 返回 `{}` ⇒ **D1/D2/D4/D5 全部报"0 项问题"**（假绿）。即：
**"配置读不出来"会被误读成"没有问题"** —— 这与本项目"except 吞异常 = 本轮失效"的铁律同源。

修法：核心新增 `_guard()`，**每个 Skill 的判据第一条必须先过健康闸门**（表能读 + 必需键非空），
并把 `_load` 的异常**留痕**（`_LOAD_ERRORS`），不再静默吞掉。反向验证见 §4 与
`tests/test_doc_consistency_skills.py::TestConfigHealthGate`（4 例）。
