# P2-4 多税种深度模型 —— 交付报告（2026-10-14）

## 一、现状扫描

| 既有资产 | 角色 |
|---|---|
| `engine/tax_impact.py::_RATES` | **税率表**（22 项：比例税种给默认税率，从量/累进税种 `rate=None`） |
| `engine/tax_impact.known_tax_types()` | **本系统分析哪些税种**的唯一权威（红线库 `taxes` 字段） |
| `engine/tax_impact.non_estimable_taxes()` | 「不参与敞口测算」的税种 + 理由（8 项） |
| `engine/tax_impact.estimate_tax()` | 按**税种 × 基数性质**相容性测算（`rate=None` ⇒ 走未量化披露） |
| `engine/revenue_authenticity.py` / `procurement_authenticity.py` / `vat_reversal.py` / `cost_recon_detail.py` / `main_biz_cost.py` / `payroll_rules.py` / `cross_enterprise_graph.py` / `phase2_deep_dive.py` / `cross_domain_negotiation.py` | **各税种的深度分析实现**（既有，散落但真实存在） |

**结论：31 个税种在红线库中有登记、22 项税率有口径、深度实现散落在 9 个既有引擎模块里**。
缺的是「**本系统对哪个税种做哪些深度分析**」这一层**可浏览、可核对、可追溯**的登记表——
这正是 P2-4 要补的。

## 二、目标

建**数据驱动**的多税种深度模型登记表：每个税种的深度模型（关注点/所需数据/实现模块/线索强度），
并**如实展示**两类缺口：① 未实现的模型（待建）；② 税率未登记（未量化）的税种。
硬约束：**代码里不得有"税种 → 模型"的判断分支**，新增一个模型**只加一行数据**。

## 四、核心实现

### 4.1 数据驱动，代码零税种分支

```json
{"tax": "增值税", "models": [
  {"code": "vat_input_output_rate_match", "label": "进销项税率匹配",
   "focus": "...", "data_required": "...", "impl": "tax_impact", "severity": "high"}]}
```

`engine/tax_deep_models.py` 只做**读表 + 装饰 + 转发**；闸门断言**代码里不得出现税种名字面量**。

### 4.2 税种与税率**薄转发**既有权威

- 税种范围 → `tax_impact.known_tax_types()`（红线库 `taxes` 字段）
- 税率/可否量化 → `tax_impact.tax_rate_table()`（新增只读视图，**不另判**）

闸门断言 `TI.tax_rate_table()` / `TI.known_tax_types()` 两个**带前缀的调用**必须存在
（首版只查裸函数名 ⇒ docstring 里提到该词就假绿，已收严）。

### 4.3 两类缺口**如实展示**，不用默认值掩盖

| 缺口 | 字段 | 处置 |
|---|---|---|
| 模型尚未实现 | `implemented=false` + `impl_note` | 页面标「待建」，**不假装已实现** |
| 税率未登记 | `quantifiable=false` | 页面标「未量化」+ 原样透出"为什么算不出来" |

### 4.4 实现**可溯源**

每个非空 `impl` 必须对应 `engine/<impl>.py` **真实存在**；闸门逐个校验文件。
（首版曾把 `vat_reversal` 误写成不存在的模块名，反向验证 S1 立即抓出。）

## 七、未完成 / 风险

- **21 个税种尚无深度模型登记**（住房公积金/关税/出口退税/地方教育附加/城镇土地使用税/契税/资源税/环保税…）：
  属**登记缺口**，页面如实列出。补法：在 `config/tax_deep_models.json` 加一行（**不改代码**）。
- **3 个模型标「待建」**：实现须落在既有引擎模块（不建议新起模块），补完只需把 `impl` 指向该模块。
- 模型与**红线/规则的映射**未做（本表是"分析视角"，不是规则库的替代）——两者关系需业务确认。
- 线索强度 `severity` 是**参考值**，**不是风险等级**（页面已显式声明），未参与任何评分。
