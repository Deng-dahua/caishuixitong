# 系统规则库 V1.0

**生成时间**：2026-10-08 10:51
**口径**：本文件是**规则索引**（每类规则的唯一权威落点 + 文件 + 作用），不复制规则内容，避免与配置表双头维护。

## 一、规则清单

| # | 规则域 | 唯一权威文件 | 作用 | 类型 |
|---|---|---|---|---|
| 1 | 重复判定（六类 + 必要重复白名单 + 阈值） | `config/dedup_rules.json` | 定义完全/近似/结构/事实/套话/段内重复与白名单 | 配置 |
| 2 | 法定限额与税率 | `config/tax_limits.json` | 限额公式、差异性质（永久性/时间性）、适用税率 | 配置 |
| 3 | 结论分级与一票否决 | `config/conclusion_grades.json` | L1~L4 分级、verdict 映射、V1~V6 否决触发 | 配置 |
| 4 | 编号规则（底稿层 + 报告层） | `config/numbering.json` | WB-* 与 R/C/F/D/S/L/T 短号与引用格式 | 配置 |
| 5 | 报告结构（章节 + 六段式） | `config/report_structure.json` | 9 章职责、六段式写作规则、原→新映射 | 配置 |
| 6 | 质量门禁（四道 38 条） | `config/quality_gates.json` | A 证据链/B 逻辑/C 归档/D 整洁 | 配置 |
| 7 | 归档规范 | `config/archive_spec.json` | 底稿号、页眉页脚、索引、导出包 | 配置 |
| 8 | 行业参数（10 个行业包） | `config/industry_params.json` | 必查资料、风险族、指标、等级调整、模板 | 配置 |
| 9 | 行业基准与别名（66+ 基准 / 164 别名） | `static/industry_data.json` | 行业基准值与业态别名映射 | 数据 |
| 10 | 替代程序库 | `config/alternative_evidence.json` | 资料缺失时的替代核对程序 | 配置 |
| 11 | 根因登记 | `config/root_causes.json` | 根因→症状→修复落点 | 配置 |
| 12 | 模块路线图 | `config/module_roadmap.json` | 14 模块 8 项定义 + P0/P1/P2 | 配置 |
| 13 | 文书一致性（D1~D5） | `config/doc_consistency.json` | 文档数字/规则引用/残留/术语一致性 | 配置 |

## 二、引擎实现

| 模块 | 唯一权威 | 说明 |
|---|---|---|
| 重复判定 | `engine/dupkit.py` | 段落级 Jaccard / 句子级 SequenceMatcher.ratio |
| 编号 | `engine/numbering.py` | `NumberingService` + `ReportNumbering` |
| 结论分级 | `engine/conclusion_grade.py` | 分级 + 否决 + 词表双向校验 |
| 事实源 | `engine/fact_store.py` | Fact 五要素 + 冲突登记（**未接入产出链**） |
| 行业解析 | `engine/industry_resolver.py` | 归一 → 基准 → 业态 → 剔除 |
| 门禁 | `engine/quality_gates.py` | 四道门禁 + `attach_to_report` 唯一接线 |

## 三、新增同类对象的方式（不硬编码的保证）

| 要新增 | 只改哪里 |
|---|---|
| 新增一个行业 | `config/industry_params.json` 的 `industries` 加一行 |
| 新增一个业态别名 | `static/industry_data.json` 的 `industry_map` 加一行 |
| 新增一类重复判据 | `config/dedup_rules.json` 加一行正则 |
| 新增一条限额项目 | `config/tax_limits.json` 的 `limits` 加一行 |
| 新增一个编号类型 | `config/numbering.json` 的 `report_layer.rules` 加一行 |
| 新增一个模块 | `config/module_roadmap.json` 加一条 |
