## 三、风险总表（CH2）新增字段：等级与证据强度分离

| 列 | 唯一权威 |
|---|---|
| 编号 | `engine/numbering.py` |
| 风险事项 | `constituent_checkpoint` |
| 风险等级 | `engine/risk_levels.py LEGAL_LEVELS` |
| 证据强度 | `engine/evidence_chain.py` |
| 闭合度 | `engine/quality_gates.py 门禁A` |
| 结论等级 | `engine/conclusion_grade.py（L1/L2/L3）` |
| 潜在税额 | `engine/tax_impact.py` |
| 需补资料 | `engine/material_names.py` |

> 原报告用同一套值同时表达「风险有多高」和「证据有多硬」，导致 closure=0 仍给出中/高等级。
> 分离后：**风险等级**回答「若属实有多严重」，**证据强度/闭合度**回答「目前拿得准几分」，**结论等级**回答「现在能认定到哪一级」。

## 四、六段式（CH3 每个风险事项的唯一写法）

| 段 | 名称 | 写作规则 |
|---|---|---|
| 1 | **事实** | 只陈述客观事实（金额/人数/笔数/比例/时间），每条引用 F-xxx；禁止分析、禁止定性、禁止重复他处已写的事实。 |
| 2 | **证据** | 列出已有证据与缺口，标注证据强度与闭合度，引用 D-xxx；关键证据缺失须显式声明。 |
| 3 | **分析** | 推理过程；须区分『账内检出』与『外部核实』，推断部分必须标明为推断。 |
| 4 | **结论** | L1 风险指标命中 / L2 待核线索 / L3 风险事项成立，三选一；风险等级与证据强度分列；关键证据缺失触发否决降为 L2。 |
| 5 | **需补资料** | 列出 D-xxx 及各自用途（证明什么）；不展开资料内容说明。 |
| 6 | **复查标准** | 补齐后如何复检、完成判据是什么、什么情况下本项不成立。 |

> 原报告是「四段式 + 总述/分述双轨」，六段式把「需补资料」与「复查标准」独立成段，
> 并取消「总述/分述」双轨——**同一事实不再有两处完整陈述**。
