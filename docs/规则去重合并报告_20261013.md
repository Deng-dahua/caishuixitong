## 4. 最终统一规则库版本号

| 项 | 值 |
|---|---|
| 现行（在库运行） | **`2026.10`** |
| **本报告确定的合并目标版本** | **`2026.11`** |
| 规则主体（合并后不变） | **176**（=91+85） |
| 候选入库后增量 | 新增 **97** 条（`action=add`）+ 合并 **141** 条（`action=merge`，不新增条数） |

**版本号口径**：

1. **本步不覆盖现有规则**（任务约束 7）⇒ `2026.11` 是**目标版本**，`2026.10` 在其入库前**始终现行有效**；
2. 入库时 `config/rule_versions.json` 的 `version` 与 `engine/rule_versions.rule_set_version()` 必须**同源同改**（本项目铁律：版本号单一权威）；
3. 登记口径：新增规则按 `action=add` 的 **97** 条逐条登记；合并规则**不改条数**，只把候选分支并入既有检测器，故规则主体由 176 → **273**。
