|---|---|---|
| release-v1.0.0（发布包） | **否** | 包内无这些脚本，MANIFEST.sha256 亦无口令 |

| 本地 git 仓库 | **是** | 6 个脚本已被 git 跟踪 |
| docs/收口_20261018/（归档文档） | **是** | 2 份已交付文档中含该口令 |

   ⇒ 仓库内不再留存口令；脚本行为不变（实测真 Chrome 24/24 仍全绿）。
