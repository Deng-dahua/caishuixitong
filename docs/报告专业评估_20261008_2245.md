## 2. 逻辑通不通 —— 通的地方与不通的地方

### 2.1 ★ 10 处无谓语残句（未修复）

固定句式（缺主语谓语，语法不成立）：

> 「从本次上传资料来看，**本企业本项已查明的风险；**未认定到构成要件的可能性中等，但能补全尚缺的5项资料来排除此项税务风险嫌疑。」

「本项已查明的风险」是名词短语，后面直接接分号 —— 应写"本项存在需核实的风险信号"。
取证：`grep -c "本企业本项已查明的风险" output/评估用_报告文本_当前.txt` → **10**（上一轮 9 处，未减少）。

### 2.2 ★ 标题里混进引擎内部推理（R9，未修复）

R9 的**标题**是：

> 企业所得税贡献率偏低（**对应风险指标：长期亏损仍持续经营：收入或成本不实；本项未认定到该指标的任何一条构成要件，也未就亏损这一前提作出认定**）

括号里那 60 字是引擎的自述，不是标题。老板看到的标题应该只有"企业所得税贡献率偏低"。
取证：`grep -n "对应风险指标：长期亏损仍持续经营" output/评估用_报告文本_当前.txt`

### 2.3 「办理顺序：第X项」直接粘在标题后（未修复，13 处）

## 3. 疑点准不准 —— 上一轮的头号错误已修正

### 3.1 ★★ 上一轮的"增值税取含税价税合计"错误：**已修正** ✅

**上一轮**报告给老板的敞口合计是 **1,243,745.73 元**，其中增值税 **1,015,900.00 元** ——
那是 4 张红冲发票的**价税合计之和**，被当成"增值税"，高估约 5~7 倍。

**当前**报告：

```
本轮潜在税额敞口（测算）：合计约 170,341.95 元
（企业所得税 105,937.73 元；增值税 57,503.77 元；城建税及教育费附加 6,900.45 元；
  个人所得税 0.00 元；社会保险费 0.00 元）
```

增值税 **57,503.77 = 958,396.23 × 6%**，且项内注明确交代了价税分离：

```
R1  basis=958396.23  增值税 rate=0.0600 amount=57503.77
    amount_context: 锚定金额为含税（价税合计）1,015,900.00 元，按适用税率 6% 价税分离为不含税 958,396.23 元
```

**这与报告自己的口径声明①（"标注为价税合计的，已按适用税率价税分离"）终于自洽了。**

### 3.2 12/16 项"未量化"——"值多少钱"仍基本没答

16 项里只有 4 项给出金额（R1、R5、R13 及合计）。**R2、R4、R15（成本列支）等影响最大的几项都没有金额。**
对老板而言，"高风险"却"不知道该准备多少钱"，决策价值有限。

### 3.3 疑点本身的质量：多数是"真信号"，值得肯定

以下几项的依据是**账内可复核的硬事实**，属真疑点：
- R1：13 张红冲发票，附**发票号码 + 被冲蓝票号 + 红字信息确认单编号 + 日期 + 金额**（可逐张去电子税务局核）；

## 4. 能否做到"铁证如山"

按你修正后的口径——**"只要企业资料被分析出涉税风险，就是事实风险"**——分两层回答：

### 4.1 事实层：**已经"铁"了**

| 要素 | 现状 | 说明 |
|---|---|---|
| 金额可复算 | ✅ | 到分（411,111.53 / 958,396.23 / 17,000.00） |
| 对象可指认 | ✅ | 到人（杨莹）、到票号（25952000000096267625）、到日期 |
| 口径可追溯 | ✅ | 有「口径说明」块声明分子分母；含税金额已价税分离 |
| **一键回溯原始行** | ❌ | 报告不给"这数字来自哪张表的第几行"，读者只能信不能核 |
| **外部数据交叉** | ❌ | 报告自述未接入工商/司法/第三方支付 |
| 统一事实编号 | ⚠ | 有 R/要件/事实/资料多套编号，但未串联成一条链 |

**结论：账内事实已达"可复核的铁"**；但"铁"要能自证，还缺"一键回溯"与"外部交叉"这两条腿。

### 4.2 定性层：**刻意不铁，且这是对的**

报告通篇用"涉嫌/不作定性/不予排除/待核事项"，第五章明列**四个结论术语**（风险信号 / 待核事项 / 已认定事实 / 违法认定），并声明"违法认定只能由有权机关作出"。**这是正确的法律边界。**

问题不是"不该免责"，而是：

> **免责语与事实陈述没有分层。** 老板读到的每一段都被"不作定性/不予排除/资料不足"包裹，导致他**看不出"哪些是已坐实的事实、哪些只是待核的线索"**。

**建议**（不改法律边界，只改呈现）：每项疑点开头加一行**事实/定性双标签**：

> **【已核实事实】** 2025 年销项红冲 4 张，价税合计 1,015,900.00 元，均有红字信息确认单编号。
> **【待核事项】** 这些红冲是否有退货/折让等合法事由，尚缺资料，不作定性。
